# Corresponding source offer

Each published BergaTransDash Native ABI 2 Artifact Manifest identifies one
MPL-2.0 corresponding-source archive by HTTPS URL, byte size, and SHA-256.
Both the Android ARM64 and iOS Device ARM64 artifacts reference that archive.

The production schema 2 Manifest is `native_artifacts.json`. Release
`native-v0.1.0-rc.2` publishes the corresponding source at:

https://github.com/becristia/berga_trans_native/releases/download/native-v0.1.0-rc.2/berga_trans_dash-native-v0.1.0-rc.2-mpl-source.tar.gz

The Manifest records the archive's exact byte size and SHA-256 digest. The
same release also contains the two binaries that reference this source offer.
