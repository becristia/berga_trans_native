# Corresponding source offer

Each published BergaTransDash Native ABI 2 Artifact Manifest identifies one
MPL-2.0 corresponding-source archive by HTTPS URL, byte size, and SHA-256.
Both the Android ARM64 and iOS Device ARM64 artifacts reference that archive.

No production ABI 2 Manifest or binary is present in this repository yet.
Until the separately authorized ABI 2 release is published, consumers must
provide `berga_trans_dash_native_artifact_manifest` pointing to a locally
verified schema 2 Manifest.
